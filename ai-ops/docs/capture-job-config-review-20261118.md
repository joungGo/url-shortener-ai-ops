# 조사 Job 설정 호환 코드 검토 · 2026-11-18

검토 대상은 AI main5931e24 위의 조사 Job 생성기, 새 설정 검증 모듈과 회귀 시험이다. 기능·회귀 오류, Secret/서비스 계정 토큰/임의 init의 전파 여부, 설정 해시 일치 및 기존 실패 거절 경계를 직접 검토했다. 별도 사람 승인이나 독립 도구 검토로 표현하지 않는다.

추가 수정이 필요한 결함은 발견하지 못했다. 현재 Slack worker의 정확한 ConfigMap·Memory 볼륨·고정 init 구조만 새로 허용한다. 기존 직접/projected 구성의 Job은 이전 결과와 동일하다. init 복사 코드를 신뢰되지 않은 Deployment에서 그대로 가져오지 않고 검증한 고정 정의로 구성하며, 런북 정책 누락·오류는 접수 전에 거절한다. worker의 config_hash 검사는 계속 적용된다.

로컬 구현 검증의 코드 3개 SHA256과 전체 1,247개 시험 성공 로그 해시를 다시 대조했다. 당시와 동일하므로 무관한 전체 시험을 반복하지 않고 정확한 PR head를 GitHub CI에서 검증한다. 부정 구성 24종, 정책 누락/오류, 로컬 CLI→큐→worker 및 저장된 실제 worker 사본의 생성 결과를 포함한다. 상세 `capture-job-config-local-20261118.md/json`은 로컬 단계 당시의 불변 기록이다.
