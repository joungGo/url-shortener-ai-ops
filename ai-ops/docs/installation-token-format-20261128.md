# GitHub 앱 설치 토큰 새 형식 수용 · 2026-11-28

상태: 2026-11-28 재설치 중 실물에서 발견해 고쳤다.

## 문제
- C03 writer 앱 설치 토큰을 발급하자 응답 토큰이 `ghs_` 뒤 **386자**였고, `-` `.` `_`가 들어 있었다.
- 우리 코드의 형식 검사 `ghs_[A-Za-z0-9]{20,255}`가 이를 거부했다.
  - 발급 도구(`recovery_pr_token`): `pr_token_response_rejected`
  - relay의 PR writer(`recovery_pr_writer`): 토큰 파일을 거부하므로 A2 자동 발행이 동작하지 않는다.
- 권한(contents·pull_requests 쓰기), 저장소(c03 하나), 수명(1시간)은 모두 기대대로였다.
- 첫 발급 토큰 1개는 형식 거부로 값을 버려 폐기하지 못했다(1시간 뒤 자동 만료, c03 한 저장소 쓰기 범위). 진단용 토큰은 형식만 보고 즉시 폐기했다(204).

## 변경
- `recovery_pr_writer.TOKEN = ghs_[A-Za-z0-9._-]{20,1020}`(최대 1024자). 공백·줄바꿈·`/` `+` `=` 등은 여전히 거부한다.
- `recovery_pr_token`은 이 정의를 가져다 쓴다(형식 정의 한 곳).
- 토큰 파일 크기 제한(4096바이트)과 다른 검사는 그대로다.

## 검증
- 실제 형식(386자, `-._` 포함)으로 발급·Secret 저장·폐기, writer 토큰 읽기를 시험했다.
- 너무 김(1021자), 너무 짧음, 공백, 줄바꿈, `/`, `+=`, 다른 접두어는 거부한다.
- 결함 변형 4/4 검출(예전 정규식, 공백 허용, 길이 상한 제거, 도구가 별도 예전 정의 사용).
